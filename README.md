# 👁 Argus — Multi-Agent Financial Research System

> *Argus Panoptes — the all-seeing giant of Greek mythology. Multiple specialized agents, each watching a different signal, feeding one orchestrator.*

Argus is a multi-agent AI system that autonomously researches stocks by orchestrating three specialized agents — market sentiment, price analysis, and SEC filing intelligence — through a shared context bus, dynamic task planning, and a full audit trail.

---

## Architecture

```
User Query
    │
    ▼
┌─────────────────────────────────────────┐
│           ORCHESTRATOR (Gemini)         │
│  Plans → Dispatches → Reasons → Synth  │
└──────────┬──────────┬──────────┬────────┘
           │          │          │
           ▼          ▼          ▼
   ┌──────────┐ ┌──────────┐ ┌──────────┐
   │Sentiment │ │  Market  │ │   RAG    │
   │  Agent   │ │  Agent   │ │  Agent   │
   └──────────┘ └──────────┘ └──────────┘
        │            │            │
        └────────────┴────────────┘
                     │
              ResearchSession
           (shared context object)
```

**What makes this genuinely multi-agent:**

- The orchestrator uses **output of Agent A to form the input of Agent B** — dynamic context flow, not static dispatch
- The chart date range is **set by the orchestrator based on sentiment output** — not hardcoded
- The 10-K questions are **generated by the orchestrator from sentiment themes** — not a generic chat loop
- Every agent call is **logged with orchestrator reasoning, latency, and confidence** in the audit trail

## Agents

| Agent | Responsibility | Key Output |
|---|---|---|
| **Sentiment Agent** | DuckDuckGo search → Gemini extraction | Score, confidence, themes, recommended date window |
| **Market Agent** | yfinance → matplotlib chart | Price chart (dynamic date range), trend classification |
| **RAG Agent** | SEC EDGAR auto-download → ChromaDB → Gemini | Targeted answers to orchestrator-generated questions |

---

## Stack

- **Orchestrator LLM:** Google Gemini 2.0 Flash
- **Web Search:** DuckDuckGo Search (no API key required)
- **Market Data:** yfinance
- **10-K Filing:** SEC EDGAR API (auto-download)
- **Embeddings:** sentence-transformers `all-MiniLM-L6-v2` (fully local)
- **Vector Store:** ChromaDB (ephemeral, per-session)
- **UI:** Streamlit

## Key Design Decisions

**Shared context over direct agent calls.** Agents never call each other. The orchestrator mediates all communication through `ResearchSession` — a single dataclass that every agent reads from and writes to. This makes the data flow explicit, testable, and auditable.

**Dynamic inputs over static pipelines.** The sentiment agent recommends how many days back are relevant given the news landscape. The orchestrator reads that recommendation and sets `date_range_start` before dispatching the market agent. Similarly, RAG questions are generated from sentiment themes — not predetermined.

**Audit trail as a first-class citizen.** Every agent invocation is wrapped in `log_agent_call()`, which records the task assigned, orchestrator reasoning, output summary, latency, and any escalation flags. This produces a complete, inspectable decision log per session.
